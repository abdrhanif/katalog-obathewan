# Plumb's Veterinary Drug Handbook (7th ed.) — structured JSON

Generated by `scripts/scrape-plumbs-handbook.cjs` from `Veternary Drug Handbook.pdf`
(Plumb's Veterinary Drug Handbook, 7th Edition, 2011, ISBN 978-0-4709-5965-7 — 1300 pages).

## Files

| File | Description |
| --- | --- |
| `plumbs-veterinary-drug-handbook-7e.json` | Full A–Z scrape: 679 entries (678 drug monographs + 1 group heading) |
| `plumbs-headings.txt` | Flat audit list of every entry with page and parsed-section count |

Regenerate:

```bash
npm run scrape:plumbs          # writes data/plumbs-veterinary-drug-handbook-7e.json
npm run scrape:plumbs:diag     # + coverage diagnostics (TOC cross-check, thin entries)
```

The script needs `pdftotext` (poppler/xpdf) on PATH; it caches the raw text layer as
`$TMPDIR/plumbs-vdh-7e.txt` and re-uses it on later runs. Pass `--text <file>` to point at an
existing dump, `--out <file>` to change the destination, `--quiet` to silence progress.

## Top-level shape

```jsonc
{
  "metadata": { "monographCount": 679, "byLetter": {"A": 64, ...}, "fieldLabelsId": {...}, ... },
  "monographs": [ /* see below */ ],
  "index": {
    "alphabetical": [ {"id": "acarbo", "name": "Acarbose", "letter": "A", "page": 16}, ... ],
    "byLetter": { "A": [ {"id": "...", "name": "...", "page": 19}, ... ] },
    "byCategory": { "antimicrobial": ["enrofloxacin", ...], ... },
    "bySpecies": { "canine": ["acepromazine-maleate", ...], ... }
  }
}
```

`monographs` preserves the book's order: systemic monographs A–Z, then the appendix
ophthalmic/topical/dermatologic monographs. `index.alphabetical` is a flat A–Z ordering by
printed name for UIs that want one list.

## Per-monograph fields

| Field | Notes |
| --- | --- |
| `id`, `name`, `aliases`, `letter` | `name` is the printed heading; `aliases` are the alternative names printed inside the heading block (salt forms, synonyms) |
| `pronunciation`, `brandNames`, `drugClass` | from the heading line and the all-caps pharmacological class line |
| `category` | therapeutic bucket derived from name/class/indication text (`antimicrobial`, `analgesic`, `anesthesia`, `cardiac`, `ophthalmic`, `dermatologic`, `antidote`, …) |
| `species` | canonical codes detected from the Doses sub-headings (`canine`, `feline`, `equine`, `bovine`, `porcine`, `ovine`, `caprine`, `camelid`, `avian`, `reptilian`, `ferret`, `rabbit`, `rodent`, `exotic`) |
| `kind` | `drug` for real monographs, `section-intro` for appendix group headings with no drug body |
| `sourcePage` / `endPage` | 1-based PDF pages |
| `prescriberHighlights` | array of bullet strings |
| `indications` | "Uses/Indications" text (paragraphs joined with `\n\n`) |
| `indicationsActions` | appendix monographs print "Indications/Actions" instead |
| `pharmacodynamics` | "Pharmacology/Actions" text |
| `pharmacokinetics` | "Pharmacokinetics" text (ADRME, half-lives, protein binding…) |
| `contraindications` | "Contraindications/Precautions/Warnings" |
| `adverseEffects` | "Adverse Effects"; appendix entries may use `adverseEffectsPrecautions` |
| `reproductiveNursingSafety`, `overdosageAcuteToxicity`, `laboratoryConsiderations` | own sections |
| `drugInteractions` | `{ text, list: [{ drug, description }], note }` — the list preserves Plumb's per-drug interaction statements |
| `doses` | `{ notes: [], groups: [{ speciesLabel, species: [], items: [{ label, text }], notes }] }` — doses as printed, per species |
| `monitoring`, `clientInformation` | bullet arrays |
| `chemistry` | `{ text, synonyms: [] }` |
| `storageStability`, `compatibilityCompounding` | text |
| `dosageForms` | `{ notes, veterinaryLabeled, humanLabeled, all }` — products and regulatory status |
| `combinationProducts`, `extraSections` | rare extra sections kept verbatim |
| `references` | `[{ authors, year, citation, raw }]` |
| `flags` | `{ fdaApproved, extralabelFoodAnimal, arciRacingClass, controlledOrRestricted }` |
| `content` | flattened `{ uses, mechanismOfAction, pharmacokinetics, contraindications, sideEffects, drugInteractions }` for search/UI parity with `public/js/drugs-data.js` |

`metadata.fieldLabelsId` maps every field to an Indonesian display label for the UI.

## Known limitations

- Text is extracted from the PDF text layer, so a few reference blocks are letter-spaced by the
  PDF's font kerning (e.g. `"(1 9 9 3 )"`); section prose is unaffected.
- `pharmacokinetics` is absent where the book itself has no such heading (≈130 monographs).
- Occurrence-level de-duplication: when a substance appears twice (systemic monograph + appendix
  ophthalmic/topical entry) the entries are merged into one record; `alsoAt` records the second
  location and which sections were merged from it.
- The book's appendices (lab reference ranges, conversion tables, fluid tables) are intentionally
  not scraped — only drug content is.
